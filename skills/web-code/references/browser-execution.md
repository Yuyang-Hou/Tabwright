# 已登录浏览器中的保存代码

仅在制作、修复或复用普通保存代码时读取本页；使用已有 WebMCP 工具不需要载入源码。
在用户选择且允许页面代码执行的浏览器能力下，使用工具实际返回的 API 文档。
能力不可用、权限未授予或需要登录时停止，不私建 CDP 桥接绕过。

先选准目标 origin、应用路径和账号/环境。自建页可共享 profile 登录态，
不保证拥有原页的未保存状态或内存数据。只关闭自己创建的页。

官方 CUA 支持的 CDP 调用示例中，先读取页面的 `cdp` capability 文档，
再将 `Runtime.enable` 和每次 `Runtime.evaluate` 放在分开的工具调用里；
确认前一条返回后再继续。初始化卡住表示尚未运行脚本，脚本调用卡住则结果未知。
这是便于定位和已验证可行的调用方式，不是消除所有宿主卡顿的保证。

保存代码可以是一个接受 JSON 输入的普通异步函数。读取文件原字节作为 `source`，
以 `(${source})(${JSON.stringify(input)})` 作为表达式，
设置 `awaitPromise: true`、`returnByValue: true` 及覆盖内部请求预算的命令超时。
检查 `exceptionDetails` 和返回值。不要手动重打一遍已有函数或重复转义整段源码。

浏览器内使用已验证的站点请求客户端；简单同源请求可用 `fetch` 配合
`credentials: 'include'`、`redirect: 'error'` 和 `AbortSignal.timeout(...)`。
这不自动解决 CSRF、签名或个人范围。即使 GET 也可能改变数据，先确认语义。
个人接口可能匿名返回公开数据，不能只凭 200 或成功字段认为身份有效。

取证优先返回字段结构或明确的白名单投影。保存代码及脱敏约定，
不要复制登录凭据、完整 HAR 或用户安装配置。调试器观察和页面行为各用独立有界调用，
事件读取要显式设置等待时间、数量和方法过滤；不要无期限等不存在的事件。

离线测试可以用 Node 标准库 `node:test`、`node:vm` 和模拟 fetch，
只运行自己检查过的代码。VM 不是不可信代码的安全沙箱。
离线通过不能代替目标网页的真实查询；浏览器可用也不能代替结果语义正确。
