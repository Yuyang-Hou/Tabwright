## Install the extension and CLI

Install the [Chrome extension](https://chromewebstore.google.com/detail/tabwright/dkfhphbajbkplddmchbdgdddioonngep),
then install the CLI with Node.js 18 or newer:

```bash
npm install -g tabwright@latest
```

The CLI's `postinstall` step installs the matching compact agent skill into
`~/.agents/skills/tabwright`. Open a new agent task after installation so it can
discover the instructions.

Check the installed copy, or install it explicitly if npm lifecycle scripts were
disabled:

```bash
tabwright skill status
tabwright skill install
```

Use `--target codex` or `--target claude` when an agent only scans its private
directory. Updates preserve user-modified copies; `--force` explicitly replaces
one. Existing domain Skills remain managed by the agent's Skill tools.

## Connect Chrome

Open the page you want the agent to use and click the Tabwright extension icon.
Run the connection check and create a session:

```bash
tabwright doctor
tabwright session new
```

The icon turns green when its tab is connected. If the check reports a problem,
follow its suggested next action. With multiple browser profiles, use a browser
key reported by `tabwright browser list` with
`tabwright session new --browser <key>`.

The extension can expose enabled pages and create additional pages in that
profile. A new connection may create an empty task tab automatically. This is
different from selecting the user's already-open page.

## Choose the intended page

Replace `2` below with the new session ID. List the available URLs:

```bash
tabwright -s 2 -e 'console.log(context.pages().map((page) => { return page.url() }))'
```

For the existing page named by the user, select one exact match and keep it in
`state.page`:

```bash
tabwright -s 2 -e '
const matches = context.pages().filter((page) => { return page.url() === "https://example.com/dashboard" })
if (matches.length !== 1) throw new Error("Select one enabled tab by its exact URL")
state.page = matches[0]
console.log({ url: state.page.url(), title: await state.page.title() })
'
```

If the task calls for a separate page, create one instead:

```bash
tabwright -s 2 -e 'state.page = await context.newPage(); await state.page.goto("https://example.com")'
```

A new page shares profile login state but does not inherit another page's
unsaved form or JavaScript state. Session variables are separate; browser tabs
are shared with the user and other agents.

## Start investigating

Tell the agent what you need to understand or accomplish. It can choose between
page inspection, screenshots, Network, source search, Debugger, and interaction.

```bash
tabwright -s 2 -e 'console.log(await snapshot({ page: state.page }))'
tabwright -s 2 -e 'console.log(await getLatestLogs({ page: state.page, search: /error|fail/i }))'
```

See the [Agent Reference](./skill.mdx) for specific APIs. Keep the session ID for
subsequent calls. When finished, close only pages created for the task and use
`tabwright session delete 2`.

## Other connections

`tabwright browser start` launches a separate Chrome for Testing / Chromium
instance with the extension bundled. It does not inherit your personal browser's
login state. You can pass a browser binary path if automatic discovery fails.

Use [MCP setup](./mcp-setup.mdx) for tool-based clients or an existing direct CDP
endpoint. The local extension workflow does not require a Tabwright cloud
account.
