The CLI executes Playwright JavaScript through the browser relay. Documentation
lookup and local metadata commands do not need a browser connection.

## Local API reference

Look up the tool relevant to the current question:

```bash
tabwright docs
tabwright docs browser --limit 80
tabwright docs network --limit 80
tabwright docs editor --limit 80
tabwright docs debugger --limit 80
tabwright docs styles --limit 80
tabwright docs performance --limit 80
```

Use `--offset` and `--limit` to read a bounded section, or `--json` for structured
output. `tabwright skill` still prints the extended agent reference.

## Connect and select a page

```bash
tabwright doctor
tabwright session new
```

`doctor` reports the relay, extension, and session
with a suggested next action. It reports connection readiness, not whether a
particular account or application task has been verified.

Replace `2` with the new session ID. List available pages, then select the one
matching the user's request:

```bash
tabwright -s 2 -e 'console.log(context.pages().map((page) => { return page.url() }))'
```

See [Installation](./installation.mdx) for exact existing-page selection. When
the task needs a separate page:

```bash
tabwright -s 2 -e 'state.page = await context.newPage(); await state.page.goto("https://example.com")'
```

## Execute code

The `-s` flag identifies the session; `-e` supplies JavaScript. In Bash/Zsh, use
single quotes around the code so the shell does not expand dollar signs,
backticks, or backslashes:

```bash
tabwright -s 2 -e 'console.log(await state.page.title())'
tabwright -s 2 -e 'console.log(await snapshot({ page: state.page }))'
tabwright -s 2 -e 'console.log(await getLatestLogs({ page: state.page, search: /error|fail/i }))'
```

For a larger excerpt, a quoted multiline string or a file avoids complicated
shell escaping:

```bash
tabwright -s 2 -e '
console.log({
  url: state.page.url(),
  title: await state.page.title()
})
'
tabwright -s 2 -f inspect-page.js
```

The file executes in the same environment as `-e`. Use absolute paths when
saving screenshots, downloads, or other Playwright artifacts.

## Sessions and browsers

```bash
tabwright session new
tabwright session list
tabwright session reset <id>
tabwright session delete <id>
tabwright browser list
```

Sessions retain separate `state` objects. Browser tabs and profile login state
are shared. Reset is for a stale connection; reselect the intended page afterward.
Close only pages the task created or the user asked to close.

With multiple profiles, `session new` selects a browser only when the connection
state identifies one unambiguously; otherwise it reports available browser keys.
Pass one explicitly with `tabwright session new --browser <key>`.

### Separate local browser

```bash
tabwright browser start
tabwright browser start /path/to/browser
```

This launches Chrome for Testing / Chromium with the bundled extension. Its
profile is separate from your personal browser.

### Existing CDP endpoint

```bash
tabwright session new --direct
tabwright session new --direct <cdp-url>
```

The browser must have debugging enabled and may require user approval.

### Explicit remote relay

```bash
tabwright --host <relay-host> --token <secret> session new
```

`TABWRIGHT_HOST` and `TABWRIGHT_TOKEN` can supply the same settings. See
[Remote Access](./remote-access.mdx) for relay binding, token handling, and
tunnels. Local CLI browser commands start a relay automatically when needed.

## Independent scripts

Business Skills can use ordinary JavaScript files through `-f`. There is no
required manifest, registry or Skill runtime. See [Independent scripts](./independent-scripts.mdx)
for authentication, input, verification and migration.

## Other commands

```bash
tabwright logfile
tabwright skill install
tabwright skill status
tabwright completions install
```

## Execution flags

| Flag                 | Meaning                             |
| -------------------- | ----------------------------------- |
| `-s, --session <id>` | Session for `-e` or `-f`            |
| `-e, --eval <code>`  | JavaScript to execute               |
| `-f, --file <path>`  | JavaScript file to execute          |
| `--timeout [ms]`     | Response deadline, default 10000 ms; not cancellation |
| `--host <host>`      | Explicit remote relay host          |
| `--token <token>`    | Relay authentication token          |

## Browser environment

| Name                                          | Purpose                                                   |
| --------------------------------------------- | --------------------------------------------------------- |
| `state`                                       | Values retained within this session                       |
| `context`                                     | Connected browser context and available pages             |
| `page`                                        | Default page; retain your intended page in `state.page`   |
| `snapshot`, `getCleanHTML`, `getPageMarkdown` | Page evidence                                             |
| `createNetwork`                               | Request summaries and selected details or response bodies |
| `getLatestLogs`                               | Buffered browser console messages and errors              |
| `getCDPSession`                               | Raw page/frame CDP access                                 |
| `createEditor`, `createDebugger`              | Running source, live edits, breakpoints, and stepping     |
| `screenshotWithAccessibilityLabels`           | Visual inspection with element labels                     |
| `require`                                     | Modules available in the execution environment            |

Use [Agent Reference](./skill.mdx) or `tabwright docs <topic>` for API details.
