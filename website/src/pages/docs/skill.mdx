This page is the extended API reference. Agents can look up the relevant
browser, Network, source, or debugging tool when needed. It is not a required
sequence to follow for every task.

The global CLI installs the compact guide from
`skills/tabwright/SKILL.md` into `~/.agents/skills/tabwright`, rather than copying
this entire page. Use `tabwright skill status` to check the installed guide, or
`tabwright skill install` if npm lifecycle scripts were disabled. Agent-specific
Codex and Claude directories are available through `--target`.

For setup, start with [Installation](./installation.mdx). Use `tabwright docs` to
list local API topics. For example, `tabwright docs network --limit 80` reads a
bounded section without a browser connection; `--offset` and `--json` are also
available. `tabwright skill` still prints the extended reference.
