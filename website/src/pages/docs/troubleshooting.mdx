## Connection state

```bash
tabwright doctor
tabwright doctor --json
```

The report covers the relay, extension, usable sessions, and discoverable Skill
connections. It suggests a next action. A healthy connection does not establish
that the intended account, page, or application operation is ready.

## Local logs

```bash
tabwright logfile
```

The relay log contains extension, MCP, and relay diagnostics. The accompanying
`cdp.jsonl` contains CDP traffic records. Credential fields are redacted and long
strings are truncated; the file rotates when its entry limit is reached.

Redaction is not a guarantee that arbitrary page data is safe to share. Inspect
only the records relevant to the issue. For a selected request's current body or
initiator, use `createNetwork` rather than assuming the log contains complete
evidence.

```bash
rg -n 'error|failed|disconnected' /absolute/path/to/relay-server.log
tabwright docs network --limit 80
```

Log files are recreated when the relay starts. They are diagnostics, not durable
task history.

## No extension connection or enabled tab

Check whether Chrome is running and the extension is installed in the intended
profile. Click the extension icon on the requested tab and run
`tabwright doctor` again.

The extension can expose enabled pages and create additional task pages.
An automatically created empty page does not replace selecting the user's
existing page. With multiple profiles, `tabwright browser list` reports keys
for `tabwright session new --browser <key>`.

## Stale session

```bash
tabwright session reset <sessionId>
```

After reconnecting, select the intended page again. A session reset does not
resolve a website's validation error, failed payment, or rejected API request.
Investigate the relevant page state and response for those problems.

## Port 19988 is occupied

An existing relay may already be serving another task. Identify the listener and
inspect its status before stopping a process:

```bash
# macOS/Linux
lsof -nP -iTCP:19988 -sTCP:LISTEN
```

On Windows, use `Get-NetTCPConnection -LocalPort 19988` to identify the owning
process. Reuse a healthy relay. Restarting it interrupts connected tasks; do not
terminate an unrelated listener just because it uses the same port.

## Slow operations

An execution timeout can be increased for an operation that is known to need
more time:

```bash
tabwright -s 2 --timeout 30000 -e 'console.log(await state.page.title())'
```

Replace `2` with your session ID. The default is 10 seconds. Inspect whether a
request is still pending, the page is blocked, or the target changed before
repeating an action. Do not blindly retry a write after an unknown outcome.

## Browser limitations

Some Chrome debugger failures leave pages appearing as `about:blank`. If
reconnecting does not help, restarting Chrome may be necessary; preserve the
user's unsaved work first.

Connecting through Playwright can also affect browser color-scheme behavior.
For a reproducible issue, include the browser and Tabwright versions plus a
small relevant diagnostic excerpt in the
[issue report](https://github.com/Yuyang-Hou/Tabwright/issues).
