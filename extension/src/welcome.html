Give your agent the browser's debugging tools

Tabwright builds on Playwriter to let your agent inspect and interact with your Chrome: page state, Network, running code, breakpoints, screenshots, and real browser actions. The agent chooses the tools that help answer your question.

Get connected

1
Install the CLI 
npm install -g tabwright@latest

This also installs the compact agent skill. Open a new agent task to discover it. If installation scripts were disabled, run tabwright skill install.

2
Connect the page you want to use

Pin Tabwright using Chrome's puzzle icon, then click it on your target page. The icon turns green when the tab is connected. 

tabwright doctor
tabwright session new
3
Give your agent a goal and a page

For example: “Use Tabwright on my open dashboard. Find out why the chart is empty using whichever page state, requests, or running code helps explain it.”

Using the CLI directly

Replace 2 with the session ID printed above. List available pages and retain the one matching your request in state.page. For work that needs its own page, create one instead: 

tabwright -s 2 -e 'console.log(context.pages().map((page) => { return page.url() }))'
# Create a page only when the task should use a separate tab.
tabwright -s 2 -e 'state.page = await context.newPage(); await state.page.goto("https://example.com")'
tabwright -s 2 -e 'console.log(await snapshot({ page: state.page }))'
tabwright -s 2 -e 'console.log(await getLatestLogs({ page: state.page, search: /error|fail/i }))'

A new page shares profile login state, but not another page's unsaved or in-memory state. Use createEditor, createDebugger, and createNetwork when code or Network evidence is more useful.

Control and data

The default relay runs locally. Connected tabs and profile login state are shared with the user and other agent sessions. The agent can create additional tabs in that profile. Chrome shows debugging indicators on controlled tabs.

Websites receive requests made in their pages. Page content returned by Tabwright goes to your agent and may be processed by its model provider. Local logs and saved source can contain page data.

The agent is responsible for your authorized scope, required approvals, and checking the result of its actions. Raw browser access does not isolate accounts or enforce application-level read/write permissions.

Connection status

  • Gray: Tab is not connected
  • Green: Tab is connected
  • Orange badge (...): Connecting to the relay
  • Red badge (!): Connection error

Run tabwright doctor for the current connection state and a suggested next action. Close only task-created pages and use tabwright session delete 2 when the session is no longer needed.
